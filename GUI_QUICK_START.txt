## Click-by-Click Demo 🎮

### Try This in Order:

1. **Select Account** → Click "Savings Account" in the tree
2. **Deposit Money** → Click "Deposit $100" → see notification
3. **Apply Interest** → Click "Apply Interest" → balance increases
4. **Switch Strategy** → Choose "Compound" in dropdown
5. **Apply Again** → See different interest amount!
6. **Transfer** → Set source, select destination, transfer $200
7. **Watch** → See approval routing in notifications

---

## What Each Pattern Does 📚

**Click buttons at bottom to see explanations:**

- 🎯 **Composite** - Account groups work uniformly
- 📢 **Observer** - Multiple notifications (Email, SMS, In-App)
- 🔗 **Chain** - Transaction approval routing ($1k → $10k → unlimited)
- ⚙️ **Strategy** - Switch interest calculations at runtime
- 🎭 **Facade** - Unified banking interface (hides complexity)
- 🔄 **State** - Accounts have states (Active, Frozen, etc.)
